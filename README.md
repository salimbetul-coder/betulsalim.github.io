# Betül Salim — Project Management Portfolio

Personal portfolio focused on requirements, Agile delivery, stakeholder coordination and release readiness.

**Live site:** https://salimbetul-coder.github.io/betulsalim.github.io/

## Structure

- `index.html`: responsive, dependency-free portfolio with light/dark themes.
- `assets/Betul_Salim_Project_Manager_CV.pdf`: supplied project management CV.
- `index.md`, `projects.md`: aligned Markdown summaries.
- `github/`, `lurentra/`: existing social-sharing landing pages.

## Preview locally

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

Content reflects the supplied September 2026 CV. Employment titles are preserved. Project summaries describe contributions without publishing internal documents or customer records. No new certifications, job titles, team sizes or budget ownership are asserted.
